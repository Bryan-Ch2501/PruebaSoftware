# Unidad II: Implantación y Mantenimiento de Software

Este repositorio contiene los materiales didácticos y ejercicios de consolidación correspondientes a la **Unidad II** de la asignatura de **Ingeniería de Software II**.

## Descripción del Proyecto
El objetivo de este repositorio es centralizar las actividades prácticas desarrolladas en **Hot Potatoes**, enfocadas en los siguientes pilares de la gestión de software:

- **Administración de Pruebas:** Estrategias, roles, técnicas y herramientas.
- **Mantenimiento de Software:** Ciclos de vida, tipos de mantenimiento (correctivo, evolutivo, preventivo) y control de calidad
  
## Tecnologías Utilizadas
- **Herramienta de autor:** Hot Potatoes 6.x / 7.x
- **Formato:** HTML/CSS/JavaScript (exportación estándar de Hot Potatoes)
- **Control de versiones:** GitHub
